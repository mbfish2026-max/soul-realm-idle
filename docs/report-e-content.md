## 集成方式

先加载 names.js、全部原有 data/*.js，再依次加载：

1. data/ext/progression.js
2. data/ext/pets.js
3. data/ext/maps.js
4. data/ext/install.js

在 systems 初始化、觉醒抽取与游戏启动之前执行 `SR.content.install()`。该调用向原数组追加内容或合并原记录字段；保留原记录对象与 id，不改存档、不监听事件。普通 script、window/globalThis 的 SR 均可运行；重复调用或重复加载扩展后安装不会重复追加。缺少基础数据/扩展脚本时明确抛出加载错误。

无需新 Tab 或 DOM 挂载。本路仅提供数据，入口脚本加载与 install 调用由集成路完成；武魂分支、试炼入口、共鸣图鉴和地图选择挂入 B 路现有角色/契兽/战斗入口。具体新增字段见 docs/interfaces.md 末尾「变更提案-e-content」。

## 跨路配合与现有限制

- 集成：加入四个脚本并调用 install；不加载这些脚本时原 MVP 完全保持原内容。
- A：读取 trial 的瓶颈条件与首领参数、地图 unlock/eggPool、boss.phases、多阶段 skillId，并按 resonances 真正匹配与冷却。现有核心仍固定双宠、固定首领预警、契心满即无配方融合；这些行为不是本路修改范围。兽卵当前全池均匀抽取，直接加载扩展会过早获得神级兽卵，必须改用地图池：万渊林建议 fox/crane/turtle/deer/hawk/tiger/bud；新图使用各自 eggPool。高阶链终点只通过蜕变获得。按设计，黑红精魄只在线渊主产出、离线封顶紫色，也需 A 的掉落策略处理，不能直接用普通渊兽年限无筛选生成黑红精魄。
- B：分支选择/费用/属性、经验与晋阶、三宠出战、被动属性、共鸣图鉴、词条与红环双技能接入。expToNext 是每境界参考门槛，不是已落地的逐级经验公式；不能直接代替原有等级算法而不复核时长。trial.requiredRings 在瓶颈等级按新开槽计，打完才可进入下一境界。红环双技能只是内容字段，不擅自改变原单 skillId 存档。
- C：按实际核心事件展示新首领预警与共鸣名称，背景应随 mapId 切换。
- D：补 bg_snow/bg_ridge、mob_snowmink/mob_iceyak/mob_slagbeetle/mob_ashram、boss_snowlord/boss_ridgelord 和新增武魂/契兽图标、轮技音画；本路没有添加或修改素材。
