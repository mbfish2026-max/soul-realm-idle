# 里程碑 1 集成交付

当前分支 integration；未切换或修改 master，未 push。

## 正式流程

index.html 是游戏入口，加载页预载森林背景、主角、灵狐及两种首波渊兽；点击开始通过可信点击解锁音频。首次显示两句原创开场，可跳过，随后武魂三选一并立即挂机。已有存档直接恢复战斗，离线收益已入账并弹窗展示，点击空白关闭。

按接口顺序加载全局脚本；main.js 接通舞台、战斗事件、掉落提示、吸收特效、sfx、存档、离线及四个底部页面。补齐经验升级与兽魂来源；契兽页可孵化首只伙伴，背包也可孵化，培养和出战真实生效。修正素材对象背景取值、怪物及契兽素材键映射，防止正式资源 404。契兽行为计数只标记存档，不再每次击杀重绘整个界面。加载页退出时不写未加载的默认存档。

mock 全目录、UI 预览与桩、舞台演示与驱动、素材预览均 git mv 至 dev。正式页面无开发页链接、无 mock 依赖。部分开发页保留旧相对路径，需单独维护；不影响游戏。

## 十部位装备

crown 头冠、robe 衣袍、belt 腰带、boots 靴履、bracer 护腕、skirt 下裳、necklace 项链、ring 戒指、weapon 法器、jade 玉佩。掉落使用十部位，背包显示部位印字和属性并可穿戴，角色页左右各五格，点已穿戴格卸下；换装返还旧装备，满包拒绝卸下。攻击、防御、生命实时计入人物及战斗。

存档结构升至 v2，localStorage key 保持 sr_save_v1；v0→v1→v2 顺序迁移。旧 head/body/larm/rarm/lleg/rleg 分别迁往 crown/robe/bracer/weapon/skirt/boots，包含背包、仓库与已穿戴物品。接口说明仅追加。

## 验证与体积

- 全部跟踪及新增 JS 执行 node --check，通过。
- node tests/run.js 枚举全部 15 个 tests/*.test.js，全部通过；新增覆盖旧装备迁移、属性加成、十格逐一穿戴和卸下。
- python3 tools/e2e.py 自动启动 python3 -m http.server，以 WebKit 390×844 从 index.html 实际点击：加载、开始、开场、觉醒、至少60秒战斗逻辑、掉落、背包、吸收成功、契兽页孵化/培养/出战、装备、自然推进首领、刷新读档、两小时离线结算及点空白关闭。
- 战斗加速仅由自动化脚本调用真实 tick，无游戏内调试入口；离线时间在导航后通过初始化脚本修改 localStorage，避开正常 pagehide 保存覆盖。
- 控制台/pageerror/HTTP错误均为零，各截图检查图片解码成功及页面无横向溢出。
- 冷缓存加载页约804 KB，进入首场战斗约1.15 MB，低于约2 MB目标；精确本次结果见 docs/e2e-integration.json。其余动作、首领及页面头像随使用加载。
- 11张主要页面截图：docs/shots/int_00_loading.png 至 int_10_offline.png。已目检加载页、角色十格、契兽及首领截图。
