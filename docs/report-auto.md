# 自动战斗交付

integration 分支，未操作 master，未 push。

自动战斗默认开启，战斗页提供开关、常驻状态角标、策略入口、实际魂技按钮和合体技按钮。关闭后普通攻击与被动技继续，主动技能由玩家点击；同一套魂力、冷却及控制状态判定用于自动和手动释放。低血时优先治疗/护盾，存在未锁定治疗物品时可消耗恢复。当前掉落表无药品，实际保命依靠魂技。

自动策略保存到 state.auto，包含英雄魂技顺序、低血阈值、首领保留合体技、推图、挑战首领、吸收成功率、只吸收适配魂技、低品质装备出售阈值。旧档补齐默认值并迁移旧自动吸收开关；已有魂技页的优先操作同步新策略。魂环仅自动填开放空槽，年限、类型、适配与成功率均通过才吸收，替换已有魂环始终保留玩家二次确认。未满足条件的精魄进入仓库并加入持久队列，仅在前台战斗页无弹窗时展示，切 Tab 与打开策略面板持续战斗且保留当前弹窗。

自动出售仅处理低于设定品质的未锁定装备，满背包溢出仓库，避免满包机制绕过品质阈值或出售锁定物品。正式入口离线复用真实战斗与掉落策略，仍按12小时上限及70%有效时间结算，包含推进、首领、魂力、死亡、自动吸收及出售；手动模式不假定离线主动施法。隐藏页面先结清前台尾段，后台计时器暂停结算，恢复按独立游标补算一次，pagehide 不覆盖隐藏游标。离线表现、音频及逐事件保存受抑制，结算后统一保存。

换环失败的通知改为在原环恢复后发送，避免战斗属性监听器在临时空环状态报错；新增带实际数值表的回归测试。

验证：21 个测试文件，全部已跟踪和新增 JS 的 node --check、全部 tests/*.test.js 通过。新增 core_auto 与 core_auto_battle 覆盖优先级、魂力、冷却、沉默、低血保命、治疗物品、首领保留和手动释放合体技、自动吸收成功率/适配/空槽、出售品质/锁定/满包、真实离线自动吸收与出售、重复领取、隐藏后计时器与重复恢复。

WebKit 390×844 跑完整 tools/e2e.py：默认开关、手动模式、策略持久化输入、点空白关闭、实际魂技手动释放、实际优先级调整、策略面板中持续战斗、觉醒/职业/吸收/替换/契兽/装备/重载/两小时离线收益。控制台、pageerror、HTTP错误均为零；图片解码、无横向溢出检查通过。目检战斗及策略截图，修正入口原有舞台高度，确保新操作区、舞台与底部收获入口在390×844完整显示。
