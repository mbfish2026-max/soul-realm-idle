# 职业、魂环与契兽技能

开局先觉醒武魂，再选逐锋、铸星、织岚、映泉、镇岳、唤灵六条修行之路。职业界面列出定位、专属攻击/防御/生命/速度成长、装备倾向和推荐武魂；允许自由组合。职业成长在 systems/stats 汇总，原有装备与武魂不被替换。

魂环就是魂技。精魄由击杀来源决定，来源渊兽的九环双分支池是唯一取得途径；108项职业效果模板用于生成来源技能，不提供第二套独立学习路线。每环一个具体魂技，吸收自动1级，不再购买解锁。渊兽图鉴逐环列出可能魂技。第1–9环最低年限分别为1、10、100、100、1000、1000、10000、10000、100000，前三环允许主动和被动，第四环起允许终极。最大999999年。

白黄紫黑红对应五品阶，分界100/1000/10000/100000年。魂技威力连续乘以 `1+log10(1+年限)×0.12`，每升级再加12%；职业适配120%、不适配85%，武魂同脉另乘115%。同脉出战契兽提供20%技能协同，combo效果还读取协同因子。界面明确列出最终适配倍率。

升级消耗20×目标等级灵晶；从1级起另消耗当前等级份技能材料，每清一波得1份。满级5。洗点收投入灵晶10%（至少20），返还升级材料与投入灵晶，保留魂环自带1级魂技。来源分支调整每次20灵晶；已升级的分支进度保留，重新切回可继续使用。更换魂环必须二次确认，显示旧技丢失；吸收失败保留旧环。

契兽沿用30物种与已有蜕变链，每种补四技能：种族天赋、主动、羁绊、蜕变。天赋被动按种族品阶增强；羁绊3段解锁，蜕变技能要求品阶与蜕变状态。五种战斗定位为输出、控制、治疗、护盾、增益。培养页显示解锁条件并可将任意已解锁技能移到优先顺序首位。30种职业×定位合体技分别配置契心门槛、冷却、魂力及特效参数。

战斗由组合效果表驱动，优先释放列表交给 `SR.skillAI.pick(actor,ctx)`。伤害、持续伤害、控制、护盾、治疗、增益、减益、召唤、群攻、连击可组合。召唤当前采用定时攻击增益表示随行灵体，不另增加永久出战位。沉默封主动技、眩晕停行动、迟缓延长敌人攻击间隔。特效仅发送fxKey，由舞台消费，粒子结束即停。

自动吸收默认关闭，技能页开关可启用；仅填空槽，不自动替换。最低年限与最低适配同时达标才吸收，阈值保存在hero.autoRing，供后续设置界面扩展。旧v1/v2档无来源魂环维持原技能，新掉落记录来源与分支；技能子版本v0迁移至v1，不变更外层存档版本。

美术清单见 skill-art-list.md；图标未制作时用同脉色已有魂环图，不使用文字占位。模拟方法与阶段曲线见 balance.md 和 balance-skills.json。
