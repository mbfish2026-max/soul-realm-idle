# 斗罗契兽 · 手机网页战斗画面 Mock（水墨清新版）

390×844 竖屏。三个页面共用 `live.css` / `live.js`，都能直接用浏览器打开，并且可以点击交互。截图在 `shots/`，由 `python3 shoot.py [页名]` 用 playwright webkit 生成。

## 页面设计要点
### p1_ring_stage.html 魂环舞台（常规挂机）
- 顶栏：地图名，加一枚「仙途」朱印，下面是波次进度条和魂力条。下方留大片空白，让画面以山水为主。
- 主角站在 6 层魂环上（白/黄/紫/紫/黑/红，CSS 椭圆描边），契兽灵狐站在左侧。3 只墨狼带着年限标签和血条走进场。
- 释放技能时，对应那一层魂环点亮并扩散一次，同时有技能名字幕、斩击线、伤害数字（暴击用大字加「暴击」印）、狐爪追击伤害、墨点粒子。
- 底部只有一排玉质圆形技能按钮（4 个技能 + 融合），会显示冷却扇形。下面是宣纸日志。最底下的演示按钮可以触发：受击/胜利/倒下/走近/重置。
### p2_boss.html 首领战
- 宣纸底的分段血条：在 66% 和 33% 处有阶段刻度，配 壹/贰/叁 三枚阶段印，另有「十万年」印。
- 进入二阶段的流程：屏幕震一次，四周泛红边，横幅写红色预警「朱焰焚天 · 3 秒后全屏灼烧」，一枚红色十万年魂环落地，并标出「十万年魂环 / 击败必掉」。
### p3_absorb.html 吸收魂环
- 被击杀的墨狼身上升起紫色光柱，魂环上浮。
- 宣纸面板包含：年限大字（1,734 年，带千年·紫印），上限条（上限 1,500，超出 234，用红色斜纹标出），公开的成功率（62%，失败 38%，并拆出构成：天赋/契合度/超限），风险红框（会掉几级、魂环是否消失），技能预览（影噬爪），三个按钮：放弃 / 存入仓库 / 吸收 62%。

## 真实实现方式
- **CSS 动画**：角色各状态（呼吸、走近、突进、施法、受击白闪加后退、融合、胜利、倒下墨散）、魂环点亮扩散、伤害数字、字幕、屏震、红边、魂环上升/落地、技能冷却（conic-gradient）。除了呼吸以外，所有动画只播放一次。
- **Canvas**：一张全屏透明 canvas，`burst()` 一次性喷出墨点和火星粒子。粒子全部消失后 requestAnimationFrame 就停下，不会常驻占用。
- **DOM 结构**：每个角色是一个 0 尺寸的锚点（脚底中心），里面放 img，切换状态就是换贴图加一个一次性 class。
- 视差：背景层可以按波次做 translateX 慢移（当前 mock 是静态图）。

## 动作系统
### 状态机
`idle(呼吸循环) → move → idle`；`idle → attack | skill | fusion → idle`；任何状态 `→ hit → idle`；`→ win`（保持）；`→ die`（终态，墨散）。每个状态都有 DUR（时长），到时自动回到 idle；win 和 die 不回。
### 主角 + 契兽 技能时序（ms）
| t | 事件 |
|---|---|
| 0 | 按下按钮，主角进入 skill |
| 120 | 对应魂环点亮、扩散，喷粒子 |
| 140 | 技能名字幕 |
| 260 | 主角 attack，契兽同时 attack 扑出 |
| 380 | 斩击线 |
| 480 | 目标 hit（白闪加后退），扣血，出伤害数字（暴击时加印），写日志 |
| 620 | 狐爪追击伤害 |
| 700 | 判定是否击杀，击杀后进入 die |
### 融合时序（ms）
0 双方进入 skill → 60–360 六环依次点亮 → 200 字幕「灵元融合」→ 420 双方进入 fusion（残影）→ 640 屏震，全体敌人受击 → 1300 结算击杀；全部死亡时双方 win，出「胜」字。
